# Step em Movimento

Landing page estática do produto digital **30 fichas com 120 exercícios usando step**.

## Estrutura

- `index.html`: página completa e responsiva
- `assets/step-hero.webp`: imagem otimizada da oferta
- `vercel.json`: configuração de publicação

O projeto pode ser publicado diretamente pela Vercel, sem etapa de build.
